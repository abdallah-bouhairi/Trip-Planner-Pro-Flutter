# Quick Trip Planner Pro - Flutter Mobile App

### 📝 Project Overview
A complete, functional mobile application built with **Flutter** and **Dart** that solves the real-life problem of quick trip organization. This project is built without any local or online databases, relying on efficient state management and memory handling.

---

### 🚀 Key Technical Concepts Applied
This project demonstrates a deep understanding of the Flutter framework by implementing the following:

* **Advanced State Management:** Utilizing `StatefulWidget` and `setState` to handle real-time UI updates.
* **Memory Management:** Implemented the `dispose()` destructor to clear `TextEditingControllers` and prevent memory leaks.
* **Form Handling:** Used `TextEditingController` for managing user input, along with `InputDecoration` for a professional UI.
* **Context & Feedback:** Leveraged `BuildContext` to display `SnackBars` for user validation and feedback.
* **Reusable Components:** Created a **Custom Widget Class** (`MyTextWidget`) to ensure clean and maintainable code.
* **Selection Widgets:** Integrated `DropdownButton`, `Radio Buttons`, and `Checkboxes` for a complete data entry experience.
* **Navigation & Routing:** Implemented **Named Routes** using the `Navigator` class for clean app architecture.
* **Responsive Layout:** Used `Column`, `Row`, `SizedBox`, and `ListView.builder` for a responsive design based on **Logical Pixels**.

### 🛠️ How to Run the App
1.  Ensure you have the **Flutter SDK** installed.
2.  Clone this repository:  
    `git clone https://github.com/abdallah-bouhairi/Trip-Planner-Pro-Flutter.git
3.  Navigate to the project folder and run:  
    `flutter pub get`
4.  Launch the app on an emulator or physical device:  
    `flutter run`
